# Raven.
An scriptwriting / bookwriting tool for cinema writter and beginners. 

Raven is an individual made through love and hard work for beginners writer it's comes with many features :

1. Typewriter effect && Typewriter sound (customisable)
2. Ai Assistant (customisable && personal Api keys based)
3. Only PDF Export ( currently )
4. Scene Timeline
5. Story Timeline
6. Character Relationship
7. Character Roaster
8. Beat relationship
9. foucs mode
10. words counter
11. Cursor colour and rainbow blink effect
12. R Format && Shortcut Typing
13. RDX Format export/import 
14. Screenplay/book writing
15. 
    These are the current features that may be expanded.
